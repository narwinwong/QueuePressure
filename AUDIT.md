# What can be verified here

This repository is a clean publication snapshot of a failed fixed reference screen, not the original private research repository. It contains no quote rows, selected trades, account data or private Git history.

The public queue_screen.py mechanically extracts unchanged pure engine definitions and constants from the frozen implementation. It removes the original production driver, filesystem provenance checks and unrelated synthetic-method dependency. test_queue_screen.py contains fifteen fabricated engine controls adapted only for the module name; it excludes four private production-guard tests. The exported definitions are compared by Python AST during preparation. No historical outcome is regenerated to prepare this snapshot.

The original independent specialist agent found validation and guard gaps before evaluation; those were fixed before the single run. Nineteen synthetic controls passed independently with networking disabled. A later independent audit reconciled 3,074 saved development trades, costs, recorded times, quantities, controls, blocks and receipt hashes without rerunning the strategy or reading the archive. That establishes internal record consistency, not an independent source reconstruction of first-arrival selection, omitted cancellations or market completeness. These reviews were performed by agents, not human reviewers.

The public verifier checks a reviewed allowlist, canonical text/byte hashes, exact aggregate cost/block/control arithmetic and negative disposition. It does not authenticate data origins independently, reproduce raw selection, prove fills or certify an edge. The manifest is versioned publication evidence, not a cryptographic signature by the data provider. Rebuilding the figure uses saved aggregates only. Install no packages to run the standard-library checks; matplotlib is optional for plotting.

The original public sample is not redistributed. The source's familiarization access was not treated as raw redistribution permission. No licence to third-party data is granted here. No p-value, OOS, funded-return or prop-firm payout finding exists.
